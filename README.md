# ピクセル・ブリゲード (Pixel Brigade)

コンピュータ（モンスター軍）と戦うシングルプレイのオートバトル型ブラウザゲーム。
Android / iPhone / iPad のブラウザ向け（縦画面・タッチ操作、ホーム画面追加可）。

## 起動
```
npm start            # python3 -m http.server 8080
# → http://<PCのIP>:8080/ をスマホ/タブレットで開く
```
ビルド不要の静的ファイルのみ（index.html / css / js）。任意のWebサーバに配置すれば動作します。

## 遊び方
- タイトル → ホーム（所持キャラ・コイン・装備を確認、ショップで仲間雇用/装備購入、キャラをタップして装備変更）
- ゲームスタート → 自陣（下3行×5列）に配置。控えのキャラを選んでマスをタップ、またはドラッグ（人数制限なし・最大15マスすべてに配置可）
- 同じ種類のキャラを重ねると合体してランクアップ（最大★10）。別の種類は合体不可（入れ替え）
- バトル開始 → 各キャラが射程まで移動して自動攻撃。全滅した側の負け
- 勝利で多くのコイン＋次ステージ、敗北で少しのコイン＋リトライ。ステージが進むほど敵が緩やかに強化（1ステージごとに総戦力 約+7%、全100ステージ想定。100以降も続行可）
- 言語：日本語 / English / 中文 / 한국어

## 構成
- `js/data.js` ステータス・装備・敵編成・報酬
- `js/battle.js` 戦闘シミュレーション（DOM非依存）
- `js/sprites.js` ドット絵をコードで生成（勇者5種・モンスター5種 × 待機/歩行2/攻撃2/被弾/ダウン）
- `js/store.js` セーブデータ（localStorage）
- `js/i18n.js` 多言語
- `js/main.js` 画面・入力・描画

## テスト
```
npm install && npx playwright install chromium webkit
npm test     # ロジック単体テスト + Playwright E2E (Pixel 7 / iPhone 14 / iPad Pro 11)
```
スクリーンショットは `shots/` に保存されます。
