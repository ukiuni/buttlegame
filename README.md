# ピクセル・ブリゲード (Pixel Brigade)

コンピュータ（モンスター軍）と戦うシングルプレイのオートバトル型ブラウザゲーム。
Android / iPhone / iPad のブラウザ向け（縦画面・タッチ操作、ホーム画面追加可）。

## 起動
```
npm start            # python3 -m http.server 8080
# → http://<PCのIP>:8080/ をスマホ/タブレットで開く
```
ビルド不要の静的ファイルのみ（index.html / css / js）。任意のWebサーバに配置すれば動作します。

## 遊び方
- タイトル → ホーム（所持キャラ・コイン・装備を確認、ショップで仲間雇用/装備購入、キャラをタップして装備変更）
- 装備：ショップで1個・×10・最大までまとめ買いできる。同じ装備は所持品で「合体」でき、レベルが加算される（ブロンズソード×10 → ブロンズソード+10）。攻撃・HP・防御はレベルに比例、スピードリングの攻撃間隔短縮は最大50%に向けて伸びる。装備中のものは合体に使わない。合体は「元に戻す」可能
- おまかせ編成は配置・合体のあと、所持品の装備（合体で外れた装備も含む）を、戦力（攻撃×HP×防御）が一番上がるキャラに装着する。場に出ているキャラ同士で装備を付け替えることもある。計画の一覧に装着内容が表示され、「元に戻す」可能
- ゲームスタート → 自陣（下3行×5列、ステージ100からは10列×5行の50マス）に配置。控えのキャラを選んでマスをタップ、またはドラッグ（人数制限なし・最大15マスすべてに配置可）
- 同じ種類のキャラを重ねると合体し、2体のランクが加算される（★3＋★5＝★8）。ランクに上限はなく、★100を超えても何度でも合体できる。別の種類同士の合体は不可（別の種類は入れ替え）。盤面のバッジは大きなランクを短く表示（★1.2K、★250K、★2.5M など。詳細画面では正確な値）。補助魔法師の攻撃力アップは最大+100%で頭打ち
- 一括操作
  - 控えは職ごとに1枚の束（×数）で表示。束を配置済みの同じ職へドラッグすると「一括合体」：使う数を −/＋・スライダー・最大で選び、合体後のランクを確認してから実行
  - キャラ詳細から「一括合体」「ロック」（ロック中のキャラは合体の素材にならない）
  - 配置画面の「おまかせ編成」：空きマスを控えで埋め（近接は前列・遠距離は後列）、残りを同じ職へ合体。「均等に強化」「前列に集中」を選び、変更一覧を確認してから実行
  - ショップで ×10・最大 のまとめて雇用
  - 一括合体・おまかせ編成・まとめて雇用は、直後に表示される「元に戻す」で取り消せる（6秒間）
- バトル開始 → 各キャラが射程まで移動して自動攻撃。全滅した側の負け
- 勝利で多くのコイン＋次ステージ、敗北で少しのコイン＋リトライ。ステージが進むほど敵が緩やかに強化（序盤は1ステージ約+20%、ステージ100付近は約+7%、全100ステージ想定、ステージ100は★80〜100＋装備が目安。100以降も続行可）
- 防御力：ランクに応じて上がり、受けるダメージを割合で減らす（ダメージ＝攻撃²÷(攻撃＋防御)。防御が攻撃と同じならダメージ半分）。キャラ詳細に「同ランクの剣士から受けるダメージ」を表示。魔法と毒は防御無視
  - シールダー：防御力が特に高く（基本20）、周囲1.5マスの味方の防御力を自分の防御力の40%ぶん上げる（複数のシールダーは重ならず一番強い効果だけ）。範囲は配置中も戦闘中も点線の銀色の円で表示され、守られている味方には小さな盾のマーク。敵のシールダーも同じ効果（赤い点線の円）
- 魔法（魔法使い・リッチ・召喚士のふだんの攻撃）は範囲攻撃。狙った相手の周囲（魔法使いは半径1.25マス）にいる敵全員の「最大HPの一定割合」を削る（防御無視）
  - 割合：魔法使い 8%＋ランクごとに0.06%（最大25%）、リッチ 4%＋0.04%（最大15%）、召喚士 3%＋0.03%（最大10%）。武器や補助魔法師の攻撃力アップでも割合が上がる（詳細画面の「魔法（最大HP比）」に表示）
  - 演出：詠唱が始まると狙った場所に有効範囲（実際の範囲と同じ大きさの円）を示す魔法陣（回転するルーン）が現れ、命中の瞬間に光の柱が落ちる。範囲の円は命中後も約1秒表示（戦闘速度を上げても最大2倍速まで）。巻き込まれた全員にも細い光の柱。色は味方の魔法使い＝金、敵の魔法使い＝紫、リッチ＝緑、召喚士＝水色
  - 敵も魔法を使う：ステージ2以降の敵編成には必ず魔法使いがいる（およそ8体に1体）。高ランクの味方でも最大HPの割合で削られるので、回復役や魔法使いを先に倒す編成が有効
- 仲間は10職。ショップで雇用（初期メンバーは剣士・魔法使い・弓使い・シールダー・ヒーラー）
  - 槍使い：溜め（約1.1秒）の後、一直線に一定距離を突進して大ダメージ。外れても止まれない
  - 盗賊：足が速くHPは低い。前線をすり抜け、HPが低く攻撃力の高い敵を優先して狙う
  - 補助魔法師：近くの味方の攻撃力を上げる（+20%、ランクごとに+0.3%）
  - 召喚士：4秒間呪文を唱えてドラゴンを召喚（同時に1体まで。スタンで詠唱中断）
  - 魔法防御師：自分の周り（半径1.6マス、ランクごとに+0.004、最大2.6）に結界を張り、結界内の味方に当たる敵の魔法を完全に無効化（「無効」と表示）。結界は配置中も戦闘中も青い半透明の円（六角形の模様）で表示され、魔法防御師について動く。倒れると消える
- ステージ100から盤面が自陣・敵陣とも10×5の50マスに拡大。それまでの15マスの配置は、同じ行・中央寄せで引き継がれる（5×3用の配置も別に保存）。敵の数はステージ100の15体から1ステージごとに1体増え、ステージ135で50体
- 敵モンスターは12種類。ステージが進むと新しい攻撃スタイルの敵が登場（準備画面で敵をタップすると説明を表示）
  - ダークバット（ステージ3〜）：飛行。前衛を無視してHPの低い相手を急襲
  - 毒スライム（6〜）：攻撃で毒（防御無視の継続ダメージ）
  - ストーンゴーレム（10〜）：地面を叩いて範囲ダメージ＋スタン
  - ベビードラゴン（15〜）：一直線に貫通する炎のブレス
  - リッチ（20〜）：闇の魔法、3回に1回スケルトン兵を召喚
  - 結界インプ（25〜）：魔法防御師と同じ結界を張り、結界内のモンスターに当たるこちらの魔法を無効化（結界はピンク色で表示）。1編成に1体まで（10体以上の編成では2体まで）。物理攻撃で倒せば結界は消える
- BGM（オリジナル曲。音声ファイルは使わず Web Audio API でチップチューンを合成）
  - タイトル・ホーム・編成中：待機曲（ハ長調・92BPM。やわらかいメロディとアルペジオ、ドラムなし）
  - バトル中：バトル曲（イ短調・152BPM。オクターブで刻むベース、16分のアルペジオ、ドラム）
  - 勝利・敗北時は短いジングルの後、待機曲に戻る
  - タイトル・ホーム・バトル画面上部のスピーカーボタンでオン/オフ（設定は保存）。スマホのブラウザは最初のタップで音が出るようになる。アプリ切替・画面ロック中は停止
- 言語：日本語 / English / 中文 / 한국어

## PWA・公開
- PWA 対応：ホーム画面に追加するとアプリとして全画面で起動（`manifest.json`、アイコンは `icons/`）。`sw.js`（Service Worker）が初回アクセス時にゲーム一式をキャッシュし、オフラインでも遊べる。オンライン時は常に最新版を取得
- GitHub Pages への自動公開：`main` ブランチに push すると GitHub Actions（`.github/workflows/pages.yml`）がテスト（単体＋Playwright）を実行し、成功したらゲームのファイルだけを GitHub Pages に公開。公開のたびに Service Worker のバージョンがコミットに合わせて更新される
- 初回のみ、GitHub のリポジトリ設定 Settings → Pages → Build and deployment の Source を「GitHub Actions」にする

## 構成
- `js/data.js` ステータス・装備・敵編成・報酬
- `js/battle.js` 戦闘シミュレーション（DOM非依存）
- `js/sprites.js` ドット絵をコードで生成（勇者10職＋召喚ドラゴン・モンスター12種 × 待機/歩行2/攻撃2/被弾/ダウン）
- `js/audio.js` BGM（楽譜データと Web Audio による再生）
- `js/store.js` セーブデータ（localStorage）
- `js/i18n.js` 多言語
- `js/main.js` 画面・入力・描画
- `sw.js` Service Worker（オフライン対応）／`manifest.json`・`icons/` PWA 設定

## テスト
```
npm install && npx playwright install chromium webkit
npm test     # ロジック単体テスト + Playwright E2E (Pixel 7 / iPhone 14 / iPad Pro 11)
```
スクリーンショットは `shots/` に保存されます。
